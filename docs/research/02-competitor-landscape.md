# Agentic AI Chrome Extensions — Competitive Landscape

> Source: DataCamp "Top Agentic AI Chrome Extensions" (https://www.datacamp.com/de/blog/top-agentic-ai-chrome-extensions) + each product's official site / Chrome Web Store.
> Pricing marked `~` is market estimate, not from the article.

## Per-Extension Profiles

### BrowserAgent — https://chromewebstore.google.com/detail/jphkkablogbfneefecondchaafbdaomc
- **Does**: Runs private, cost-free AI agents fully inside Chrome to automate browser tasks, no cloud.
- **Features**: Local/on-device execution; privacy-first (no data collection); no-code + scriptable workflows; custom agent export; lightweight.
- **Models**: Local/on-device (e.g. Llama 3 on capable hardware).
- **Pricing**: Free ($0 with local models).
- **Integration**: In-browser DOM automation, local session.
- **USP**: Fully local, zero-cost agents that never send data off-machine.

### HARPA AI — https://harpa.ai
- **Does**: Hybrid agent — chat with pages/PDFs/YouTube + automate workflows (monitoring, extraction).
- **Features**: Talk to pages/PDF/YouTube; web automation + page monitoring; email/writing assist; multi-model routing; privacy-focused.
- **Models**: GPT, Claude, Gemini, DeepSeek, Perplexity, local Llama.
- **Pricing**: Free tier + CloudGPT token-based paid usage (~$12/mo tiers).
- **Integration**: Sidebar/overlay chat + DOM automation + scheduled monitoring.
- **USP**: One extension bridging many LLMs with full web automation + IFTTT-style chaining.

### Bardeen — https://www.bardeen.ai
- **Does**: Turns plain-English into multi-step browser automations ("playbooks") across 100+ apps.
- **Features**: NL→automation (Magic Box); 1,000+ templates; background/event triggers; 100+ integrations; scraping/data-transfer.
- **Models**: Undisclosed (LLM-backed builder).
- **Pricing**: Free tier; Professional ~$20+/mo.
- **Integration**: DOM automation + scheduled/background triggers.
- **USP**: Describe a workflow in English, it builds the automation.

### Zapier Agents — https://zapier.com/agents
- **Does**: AI agents that take action across thousands of connected apps with page-aware assistance.
- **Features**: Action in 7,000+ apps; agent-to-agent collaboration; activity dashboard; page-aware chat; trigger-based runs.
- **Models**: Undisclosed (LLM-backed).
- **Pricing**: Free to start; paid ~$33/mo.
- **Integration**: Sidebar/page-aware chat tied to Zapier integration backend.
- **USP**: Deepest app-action reach (7,000+ integrations) — "do, don't just say".

### Sider — https://sider.ai
- **Does**: AI sidebar to chat with any page/file and compare multiple models side by side.
- **Features**: Group Chat (compare models); in-page sidebar; file/page chat; translation suite; writing/summarization.
- **Models**: GPT, Claude, Gemini, DeepSeek, Grok, Llama.
- **Pricing**: Free tier; paid ~$4.20–10/mo.
- **Integration**: Sidebar overlay.
- **USP**: Run several top models in parallel and compare answers.

### Merlin — https://www.getmerlin.in
- **Does**: 26-in-1 assistant — summarize videos/PDFs, chat with files, translate across the web.
- **Features**: 26 tools; instant video/PDF summaries; chat with files; 128+ language translation; multi-model.
- **Models**: GPT o3, Claude 4.5 Sonnet, Gemini 2.5, DeepSeek, others.
- **Pricing**: Free tier; paid ~$12/mo.
- **Integration**: Sidebar/overlay assistant.
- **USP**: Broadest all-in-one toolset across premium models.

### Perplexity — https://www.perplexity.ai
- **Does**: Research-focused AI condensing articles/pages into verified, cited overviews.
- **Features**: Summarize articles/pages; cited cross-reference verification; voice commands; in-context Q&A; live web answers.
- **Models**: In-house Sonar + partner models (mix undisclosed).
- **Pricing**: Free tier; Pro ~$20/mo.
- **Integration**: Sidebar/overlay search + summarization.
- **USP**: Source-cited, verifiable answers grounded in live web.

### AnswerAI — https://www.answerai.com
- **Does**: Study/homework helper — capture any on-screen question, return step-by-step solutions.
- **Features**: Screen capture/highlight to solve; step-by-step; geometry mode; chat tutoring; cross-subject.
- **Models**: Undisclosed.
- **Pricing**: Free tier + upgrades.
- **Integration**: Overlay/screen-capture.
- **USP**: Snap any question on screen, get a worked solution (owns the education vertical).

### Compose AI — https://www.compose.ai
- **Does**: Writing autocomplete — predictive sentence/paragraph completions across the web.
- **Features**: Predictive completion; one-click rewrite; smart email assist; tone/length; works in most text fields.
- **Models**: Undisclosed.
- **Pricing**: Free tier; paid Premium.
- **Integration**: Inline overlay autocomplete in text fields.
- **USP**: Cuts typing time with everywhere-you-type autocomplete.

### Magical — https://www.getmagical.com
- **Does**: Text-expansion + autofill — reuse snippets, move data between apps without copy-paste.
- **Features**: Reusable snippets; smart variables; autofill; cross-tab/app data transfer; template messaging.
- **Models**: Undisclosed (AI-assisted snippets).
- **Pricing**: Free tier; paid plans.
- **Integration**: Overlay/autofill across forms.
- **USP**: Eliminates repetitive typing and copy-paste between apps.

### True AI — Chrome Web Store (search "True AI")
- **Does**: Filters social/web noise (abuse/spam/low-quality) + drafts context-aware replies.
- **Features**: Auto-hide abuse/spam/hate/scams; context-aware replies; inline editing; feed cleanup; tone control.
- **Models**: Undisclosed.
- **Pricing**: Free.
- **Integration**: Overlay/content-filtering on feeds.
- **USP**: Cleans feeds and drafts smarter replies in place (owns moderation vertical).

### Agentic Workers — https://www.agenticworkers.com
- **Does**: Runs 100+ prebuilt prompt chains from a unified library across multiple chat AIs.
- **Features**: 100+ prompt chains; unified library; auto-continue for long outputs; multi-model; reusable templates.
- **Models**: ChatGPT, Claude, Gemini, Perplexity.
- **Pricing**: Free tier; paid plans.
- **Integration**: Overlay/injected toolbar inside AI chat sites.
- **USP**: One-click multi-step prompt chains overlaid on chatbots you already pay for.

### Recall — https://www.getrecall.ai
- **Does**: Captures + summarizes content (video/podcast/article/PDF/docs), reinforces with spaced repetition.
- **Features**: Capture YouTube/podcasts/articles/PDF/Docs; instant summaries; active recall (spaced repetition); auto-categorization; cross-content linking.
- **Models**: Undisclosed.
- **Pricing**: Free tier; paid Plus.
- **Integration**: Overlay capture/summarize + persistent knowledge base.
- **USP**: Summarize anything, then actually remember it (learning science).

### Liminary — https://liminary.ai
- **Does**: Captures + connects saved knowledge in a self-organizing graph that resurfaces relevant notes while you work.
- **Features**: Capture + connect knowledge; self-organizing graph; contextual in-the-moment resurfacing; cross-source linking; search/retrieval.
- **Models**: Undisclosed.
- **Pricing**: Undisclosed (likely free tier).
- **Integration**: Overlay/sidebar capture + contextual resurfacing (e.g. in Google Docs).
- **USP**: Auto-resurfaces your own saved knowledge exactly when relevant (proactive).

### Taskade — https://www.taskade.com
- **Does**: Project-management workspace with custom multi-role AI agents that automate tasks across views/apps.
- **Features**: Custom multi-role agents; multi-view PM (list/board/mind-map); 100+ integrations; AI Kits/templates; real-time collaboration.
- **Models**: Undisclosed (LLM-backed).
- **Pricing**: Free tier; paid ~$8+/user/mo.
- **Integration**: Sidebar/web-app workspace + integrations.
- **USP**: Build custom AI agents inside a full collaborative project workspace.

## Four Archetypes
1. **Automation agents** (BrowserAgent, HARPA, Bardeen, Zapier) — actually act on the world.
2. **Multi-model assistants** (Sider, Merlin, Perplexity, AnswerAI) — chat/summarize/translate.
3. **Writing/productivity helpers** (Compose AI, Magical, True AI, Agentic Workers).
4. **Knowledge "second brains"** (Recall, Liminary; Taskade straddles).

## Table-Stakes Features (appear everywhere)
- Page/PDF/YouTube summarization & chat
- Multi-model support + mid-task model switching
- Sidebar UI + inline overlay
- Tone-aware writing/reply generation
- Translation, OCR, image/PDF analysis
- Cross-platform sync (Chrome/Edge/mobile/desktop on one account)

## Gaps / Opportunities for Chrome_Buddy
1. **Privacy + true agency together** — local-first AND genuinely capable (DOM automation + on-device LLM) is wide open.
2. **Model transparency** — name the model, show token/cost usage, allow BYO key. Most hide this.
3. **Reliable multi-step autonomy with verification** — human-in-the-loop confirmation before consequential actions. Least-solved space.
4. **Memory spanning tools** — knowledge tools are siloed from automation tools; persistent cross-session memory feeding automations is missing.
5. **Affordable action-breadth** — cheaper, browser-native action layer vs Zapier's $33/mo gate.
6. **Verticals beyond education/moderation** — legal, healthcare admin, real estate, dev workflows under-served.
7. **Proactive vs reactive** — only Liminary/Recall push help unprompted; context-triggered assistance is under-exploited.

## Most Innovative Capabilities Worth Replicating
- **HARPA**: scheduled web monitoring + IFTTT chaining (autonomy without user present).
- **Bardeen**: NL→automation + event/time triggers (cleanest intent→running agent).
- **Zapier Agents**: read page then execute across 7,000 apps (deepest "do").
- **Recall**: augmented browsing + spaced repetition (proactive, privacy-respecting).
- **Liminary**: in-flow recall pushing cited snippets as you write.
- **Sider**: Group AI Chat (fan-out one prompt to many models).
- **BrowserAgent**: fully local execution (most defensible privacy posture).
- **Agentic Workers**: auto-continue + prompt-chain library overlaid on existing chatbots.

## Bottom Line
"Agentic" is used loosely — most are assistants, not agents. Pricing has compressed ($4–13/mo for capable multi-model tools; automation commands a premium). **Model-agnostic is the winning architecture.** Biggest unmet opportunity: a **privacy-respecting, model-transparent agent doing reliable, verified, multi-step work with cross-session memory** — combining BrowserAgent's privacy, HARPA's automation depth, Recall's memory, and a human-in-the-loop safety layer none currently nail.
